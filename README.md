\# Sistema de Gestión de Eventos y Participantes



Proyecto Integrador de Programación II (EIF204).



\## Descripción



Sistema de gestión de eventos y participantes desarrollado como proyecto académico. El sistema permite organizar eventos, actividades, participantes, expositores, inscripciones, asistencia, consultas y reportes.



\## Tecnologías utilizadas



\- Java

\- JavaFX

\- FXML

\- Maven

\- NetBeans



\## Funcionalidades principales



\- Inicio de sesión.

\- Gestión de eventos.

\- Gestión de actividades.

\- Inscripción de participantes.

\- Inscripción de expositores.

\- Registro de asistencia.

\- Consultas.

\- Reportes.

\- Cierre de sesión.



\## Estructura del proyecto



El proyecto utiliza una estructura basada en clases de dominio, controladores JavaFX y archivos FXML para la interfaz gráfica.



Las principales clases del dominio son:



\- `Usuario`

\- `Evento`

\- `Actividad`

\- `Persona`

\- `Participante`

\- `Expositor`

\- `Inscripcion`

\- `Asistencia`
